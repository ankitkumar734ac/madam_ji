# Birthday Surprise Static Website

This is a static GitHub Pages-ready birthday website. It has no build step and can be hosted directly from the repository root.

## Customize

- Edit `script.js`.
- Set `herName`.
- Set `birthdayMonth` and `birthdayDay`.
- Add her photos as:
  - `assets/photos/photo-1.jpg`
  - `assets/photos/photo-2.jpg`
  - `assets/photos/photo-3.jpg`
  - `assets/photos/photo-4.jpg`

The site stays locked before the birthday and shows a countdown timer. On the birthday date, it opens the full surprise page.

To preview the unlocked version before the birthday, open:

```text
index.html?preview=birthday
```

## GitHub Pages

Push these files to GitHub, then enable Pages from the repository settings. Choose the root folder of the main branch.
